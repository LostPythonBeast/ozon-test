# Progress

Круговой индикатор прогресса, выполненный в рамках тестового задания.

[Открыть демо](https://lostpythonbeast.github.io/ozon-test/)

## Возможности

- Установка прогресса от 0 до 100.
- Вращение индикатора по часовой стрелке.
- Скрытие индикатора с сохранением его места на странице.
- Независимое управление анимацией и видимостью.
- Адаптация интерфейса к ориентации экрана.

## Технологии

HTML, CSS, JavaScript, SVG. Без сторонних библиотек и фреймворков.

## Запуск

Скачайте проект и откройте `index.html` в браузере.
Установка зависимостей и сборка не требуются.

## Управление

- **Value** — значение прогресса от 0 до 100.
- **Animate** — включение и выключение вращения.
- **Hide** — скрытие и отображение индикатора.

## API

Функции принимают DOM-элемент контейнера индикатора:

- `setValue(block, value)` — устанавливает значение прогресса.
- `setAnimation(block, isAnimated)` — управляет анимацией.
- `setHidden(block, isHidden)` — управляет видимостью.

## Структура проекта

- `index.html` — разметка.
- `style.css` — стили и анимация.
- `progress.js` — функции управления индикатором.
- `script.js` — обработчики демонстрационной панели.
